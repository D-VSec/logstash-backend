Runtime flow:

VM logs
	-> Fluent Bit
	-> filesystem buffer and rotated spool files
	-> logstash-archiver
	-> timestamped logs_archive_YYYYMMDD_HHMMSS.tar.gz
	-> local archive directory or Cloudflare R2

Reserved directories are intentionally kept for future implementation:

	internal/azure    Azure-specific services and provisioning
	internal/config   Shared application configuration
	internal/pipeline Fluent Bit configuration generation and validation
	pkg               Public packages shared by external consumers
